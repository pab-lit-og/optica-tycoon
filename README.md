# Óptica Tycoon

Juego de gestión de una óptica (1995–2025) al estilo de *Game Dev Tycoon*: empieza con un puesto de gafas en el mercado y llega a una óptica insignia con gabinete, taller, laboratorio, tienda y marketing.

**Jugar:** https://pab-lit-og.github.io/optica-tycoon/

- Funciona en el navegador (ordenador, iPad, móvil). En iPad/iPhone: Safari → Compartir → «Añadir a pantalla de inicio» para jugar a pantalla completa y sin conexión.
- La partida se guarda en el propio dispositivo. Para pasarla a otro: Menú ☰ → Exportar partida / Importar partida.
- Sin servidor, sin cuentas, sin anuncios, sin conexiones externas.
